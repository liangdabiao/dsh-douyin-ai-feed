# AI抖音信息源

每日自动扫描抖音 AI 相关作品，按互动量（点赞/分享/评论）筛选最火内容，智能聚类后生成精美 HTML 日报。

## 数据规则

- **更新时间**：每日 16 点更新前一天数据（当前时间 ≥16 点查昨天，<16 点查前天；指定日期直用，或用 startTime/endTime 自定义范围，开始含、结束不含）
- **默认关键词**：AI（可换 ChatGPT、AI视频 等）
- **单次查询**：pageSize 默认 200
- **聚类**：完全由当天作品的 type/topic 标签决定——首标签聚类 → 小组（<2 篇）并入「其他」→ 超过总量 50% 的大类按第二标签二次拆分 → 再合并小组；组内按点赞+分享+评论降序
- **数值格式**：1234 → 1.2k；12345 → 1.2w

## 鉴权

需要 RedFox API Key（`ak_` 开头，[红狐 hub](https://www.redfox.hk/settings/api-keys?source=github) 获取）。优先级：插件配置 > 面板「设置」页 > 环境变量 `REDFOX_API_KEY`。

## 工作流

### 1. 抓取与聚类

`douyin_ai(action="fetch", keyword="AI")` —— 同步秒回：入库（同关键词+日期覆盖）+ 分类作品一览（每个分类 TOP10：标题/作者/点赞/分享/评论/作品直链）。

### 2. 输出总结

把分类作品一览完整输出给用户，并解读：
- 各分类的作品亮点与头部作品特征
- 今日 AI 内容风向（**分类由当天内容聚类决定，不要预设分类名**）
- 数值来自接口如实展示，严禁估算编造

### 3. 生成 HTML 日报

`douyin_ai(action="html")` —— 深色青风 HTML（抖音 #25F4EE 主题）：分区卡片、封面图、互动数据、作品直链。面板可直接查看。

### 4. 订阅每日推送

用户要订阅时用 **dsh 定时任务**（schedule_create，target 建议 new_once）：每天 16:00 触发，prompt 按「fetch → 总结 → html」流程写。**创建前先跟用户确认频率**，建完报告任务 id 与下次触发时间。

## 对话输出要求

总结执行结果时，除数据概览外保留两个引导区块的链接（Markdown 超链接形式）：
1. 订阅引导：需要每日下午 4 点自动推送吗（dsh 定时任务实现）
2. 单平台深挖引导：小红书爆款笔记（dsh-xhs-weeklytop）、公众号热门文章、抖音作品查询、B站作品查询——按用户实际安装的插件推荐

## 错误处理

| 情况 | 处理方式 |
|------|---------|
| 未配置 RedFox API Key | 引导到面板「AI 抖音日报 → 设置」填写 |
| 空结果 | 如实说明，建议换关键词或日期，不要编造 |
| 3106/3107（Key 错误） | 提示检查 Key |
| 积分不足（3201） | 提示充值地址 |
| 限频（3108） | 工具已自动退避 5s 重试一次，仍失败则稍后再试 |

## 在 DSH 插件里使用

- `douyin_ai` 工具负责抓取/聚类/HTML 日报；热点解读由你完成
- `history` 列出日报（新→旧）；对旧日报补 HTML/读明细传 `reportId`
- 面板可直查关键词/看分类卡片/生成 HTML；与对话流程共用同一份数据
